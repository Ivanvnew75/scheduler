# scheduler

Микросервис приложения mood-bot: регулярная рассылка вопросов по расписанию.

Две реплики при том, что рассылка должна произойти **ровно один раз**.
Взаимное исключение обеспечивает не Kubernetes, а распределённая блокировка
в Redis (`SET NX EX` + снятие Lua-скриптом по токену владельца).
Это Фактор 6 на практике: координация вынесена из памяти процесса
в backing service, поэтому реплики взаимозаменяемы.

## Переменные окружения

| Переменная | Обязательна | По умолчанию |
|---|---|---|
| `REDIS_URL` | да | — |
| `USERS_SERVICE_URL` | да | — |
| `TELEGRAM_SERVICE_URL` | да | — |
| `SCHEDULE` | нет | `0 9,21 * * *` |
| `TZ` | нет | `Europe/Moscow` |
| `LOCK_TTL` | нет | `5m` |
| `MOOD_QUESTION` | нет | `Как вы себя чувствуете?` |

`TZ` задаётся явно: контейнер по умолчанию живёт в UTC, и «рассылка в 9 утра»
без указания зоны означает полдень по Москве.

## Ручной запуск

```bash
kubectl -n moodbot port-forward svc/scheduler 18082:80 &
curl -XPOST localhost:18082/trigger
```
